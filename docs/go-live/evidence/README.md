# Evidence package index

Folder này chỉ chứa index/link hoặc evidence đã loại PII. Không commit DB dump, source migration thật, password, token, signed URL hoặc screenshot chứa dữ liệu nhạy cảm.

Required references: CI run + SHA, deployed smoke, UAT sign-off, migration validation/reconciliation, permission review, backup/restore drill, pilot screenshots/export samples, GO/NO-GO record. Hiện chưa có evidence thực tế ngoài local typecheck; xem `docs/qa/test-report.md`.
