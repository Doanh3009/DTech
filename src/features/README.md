# Feature Modules

Các module nghiệp vụ phát triển độc lập nhưng dùng chung routing, AppShell, permission, API utilities và design system.

Mỗi module nên giữ cấu trúc:

```text
pages/
components/
hooks/
api/
schemas/
types/
utils/
```

Prompt 1 chỉ tạo foundation và placeholder route. Business logic sẽ được thêm theo từng prompt sau.
